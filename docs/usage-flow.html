中文文章責編 Skill 怎麼工作

你不用先寫完整文章。先丟一件事、一個畫面，或一句還沒整理好的想法，Skill 會陪你把它整理成文章。

啟用 Skill 之後

先回答一個問題，再一題一題往下整理。

一條完整的寫作路徑

從零散想法走到作者確認
  1. 01 / 啟用先問你想寫什麼事件、畫面或一句想法都可以直接丟進來。
  2. 02 / 接住先抓住真正想寫的事不急著改句子，先確認文章要處理什麼。
  3. 03 / 訪談一題一題問下去整理畫面、停頓、感受、觀點與讀者會帶走什麼。
  4. 04 / 組織用破例感觀整理這是文章架構，不是固定文體或模板。
  5. 05 / 補充必要時再找資料先有清楚觀點，再補事實與例子。
  6. 06 / 成稿先排順序，再寫段落每一段都有自己的任務，作者語氣保留在文章裡。
  7. 07 / 交付由作者最後確認要不要保留、怎麼修改，決定權一直在作者手上。

橘色虛線代表可選的資料補充，不是每篇文章都需要查資料。

你要提供

一件事、一個場景、一種感覺，或一句還沒想清楚的話。

Skill 會協助

用一題一題的訪談，把內容、觀點和文章順序整理出來。

你保留決定權

每一段都可以改、刪、重排，最後由你確認能不能交付。

破例感觀是什麼

它是整理文章的四種材料。每篇文章不必四種都有，也不必照固定順序排列。

  • 破先讓讀者知道發生了什麼，或哪裡不對勁。
  • 例用具體事件、畫面或例子，讓讀者看見內容。
  • 感留下當下的感受、停頓和身體反應。
  • 觀說清楚你的看法，以及讀者能帶走什麼。

開始時只要說這句

你這次想寫哪一件事？可以只丟一個事件、一個畫面，或一句還沒整理好的想法。

不用先想標題，也不用先把文章寫完。Skill 會從你的第一個回答開始，一次只問一個問題。
