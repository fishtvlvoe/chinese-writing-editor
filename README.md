# 中文文章責編 Skill

給任何作者使用的中文寫作責編 Skill。

你不用先寫完整文章。先丟一件事、一個畫面，或一句還沒整理好的想法，Skill 會用一題一題的方式，陪你整理成文章。

## 先看使用流程

[開啟中文文章責編 Skill 使用流程圖](https://fishtvlvoe.github.io/chinese-writing-editor/)

[查看 GitHub Repo](https://github.com/fishtvlvoe/chinese-writing-editor)

## 怎麼開始用

### 1. 安裝 Skill

把這個 repo 放到 Codex 的 Skills 資料夾：

```bash
git clone https://github.com/fishtvlvoe/chinese-writing-editor.git ~/.codex/skills/writing-editor
```

如果這個 Skill 已經安裝好了，直接做下一步即可。

### 2. 啟用 Skill

在 Codex 對話中輸入：

```text
/writing-editor
```

也可以說：「請用通用中文文章責編 Skill 開始。」

啟用後，Skill 的第一句只會問這一題：

> 你這次想寫哪一件事？可以只丟一個事件、一個畫面，或一句還沒整理好的想法。

你不需要先準備標題，也不需要先寫好文章。

### 3. 先把方向說清楚

你回答第一題後，Skill 會先確認三件事：

- 這篇文章要談什麼
- 讀者看完可以得到什麼
- 這一輪要先完成哪一部分

方向還不清楚時，Skill 會繼續問問題，不會急著查資料或直接寫完整文章。

### 4. 一次只回答一題

Skill 會依序從這些地方了解你的內容：

- 發生了什麼事
- 當時看見什麼畫面
- 哪裡有停頓或轉折
- 你當下有什麼感受
- 你真正想說的觀點
- 讀者看完後可能有什麼改變

你可以回答「不知道」。Skill 會把抽象問題改成更容易回答的問題。

### 5. 用「破、例、感、觀」整理文章

`po-li-gan-guan` 是所有作者都可以使用的文章架構。它不是 Fish 專用，也不是固定文體。

| 零件 | 白話意思 |
| --- | --- |
| 破 | 先讓讀者知道發生了什麼，或哪裡不對勁 |
| 例 | 用具體事件、畫面或例子，讓讀者看見內容 |
| 感 | 留下當下的感受、停頓和反應 |
| 觀 | 說清楚你的看法，以及讀者能帶走什麼 |

每篇文章不一定四種都有，也不需要固定順序。Skill 會依照你的素材安排適合的順序。

### 6. 需要時才查資料

Skill 不會一開始就用搜尋結果替你決定觀點。

等你的看見、原因和差異比較清楚後，才會補充資料。需要研究時，Skill 會：

1. 找至少三個外部例子
2. 附上來源、用途和限制
3. 讓你挑選哪些例子要放進文章

### 7. 先有文章骨架，再分段起草

Skill 會先整理：

- 文章順序
- 每一段要完成的事情
- 標題和段落方向

接著再分段寫。你可以指定哪一句要修改、刪掉或重排。

Skill 不會在你沒有同意時，把文章骨架直接當成完整定稿。

### 8. 最後由作者確認

文章完成前，Skill 會確認：

- 方向是不是你要的
- 內容是不是你的真實經驗和觀點
- 資料來源是否清楚
- 交付格式是否符合你的需要

最後要不要保留、怎麼修改、能不能交付，都由作者決定。

## 這個 Skill 的分工

### 作者負責

提供經驗、畫面、感受、判斷和最後語氣。

### Skill 負責

對焦、提問、整理、查核、安排文章結構，並提出可選的寫法。

### Skill 不會做

不假設它認識作者，不把別人的語氣套到你身上，也不在未確認前代寫完整文章。

## Repo 裡有什麼

- `SKILL.md`：Skill 的主要工作流程
- `skills/po-li-gan-guan/SKILL.md`：破、例、感、觀文章架構
- `knowledge/`：訪談、研究、讀者價值和品質檢查
- `docs/usage-flow.html`：使用流程圖頁面
- `constitution.template.md`：作者可以自行複製的私人契約範本

## 私人資料不要放進公開 Repo

這是一個公開的通用 Skill repo。

不要把以下內容放進來：

- 個人資料
- 私人作者契約
- 未發布草稿
- 客戶資料
- 只適用於某一位作者的語氣規則

作者自己的 `constitution.md` 應該留在本機，不要推上 GitHub。
